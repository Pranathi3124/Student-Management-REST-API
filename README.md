\# Student Management REST API



\## Aim

Develop and test a REST API using Python Flask.



\## Technologies Used

\- Python 3.11

\- Flask

\- Postman

\- Git

\- GitHub



\## Features

\- Create Student

\- Get All Students

\- Get Student by ID

\- Update Student

\- Delete Student

\- Input Validation

\- Error Handling



\## Installation

pip install -r requirements.txt



\## Run Application

python app.py



\## API Base URL

http://127.0.0.1:5000



\## Testing

All API endpoints are tested using Postman.
